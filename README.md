# Cal-Adapt Archived Notebooks
This repository is an archive of Jupyter notebooks and scripts from the Cal-Adapt: Analytics Engine (AE). Everything here has been retired from active development (either superseded, one-off, or built for a specific partner/use case) and is kept only as a stable historical reference. 

Every notebook in this repository is archived. For actively maintained, up-to-date notebooks, see [cae-notebooks](https://github.com/cal-adapt/cae-notebooks) instead. Notebooks here may rely on older versions of [climakitae](https://github.com/cal-adapt/climakitae) and are not guaranteed to run against the current API. 

## How this archive is organized
- analysis/ contains exploratory of one-off climate data analyses such as event finders, uncertainty exploration, compound events, drought and wind metrics
- collaborative/ contains notebooks co-developed with specific external partners for their particular workflows
- data-access/ contains older data access/retrieval examples, since replaced by current methods in cae-notebooks
- guidance-website/ contains notebooks that generate figures/tables for the [AE guidance website](https://analytics.cal-adapt.org/); not standalone tools
- methodology/ contains walkthroughs documenting the methodology behind a metric or tool at a point in time
- user-contributions/ contains notebooks/scripts contributed by outside users or agencies for their own data-processing pipelines
